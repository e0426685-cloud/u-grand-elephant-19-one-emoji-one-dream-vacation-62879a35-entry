Entry for the [make.fun](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty **"One Emoji, One Dream Vacation"**: send exactly one emoji for your dream vacation, and a judge picks the most evocative.

## The entry

🏝️ — a desert island. Sun, sand, palm, open sea, nowhere to be. It is the postcard itself: a faraway place at a glance, specific rather than generic, and instantly readable at any size on any screen, in any culture. No words, no second emoji, nothing else.

## How it works

`main.py` (Python standard library only) validates the entry — exactly one emoji, 1–8 characters, not only white space — then writes it to `/output/entry.txt` with plain `open()` and an explicit `chmod 0644` so the grader can read it.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
